# FC-Dhar App

## Hindu Ceremony Invitation Management System

FC-Dhar is a modern web application for managing invitations to Hindu ceremonies (विवाह, गृहप्रवेश, etc.) with automatic letter generation, WhatsApp reminders, and visual design tools.

## Running the app

```bash
npm install
npm run dev
```

## Building the app

```bash
npm run build
```

For more information, see the root project README.md for complete documentation.
